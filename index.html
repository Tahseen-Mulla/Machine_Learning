What is Linear Regression?

Linear regression is a supervised machine learning algorithm used to model the relationship between an input variable X and a continuous output variable Y. It finds the straight line that best represents the observed data.

Regression model:
ŷ = b₀ + b₁x

b₀ = intercept   |   b₁ = slope   |   ŷ = predicted value

The least-squares method chooses the slope and intercept that minimize the sum of the squared residuals. A residual is the difference between an observed value and the value predicted by the regression line.
