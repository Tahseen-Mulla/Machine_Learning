WHAT YOU'LL LEARN

One lab, six areas of machine learning.

Every experiment pairs the underlying theory with runnable code and a hands-on demo — so the maths and the intuition build together, not separately.

Regression

Fit lines and planes through data to predict continuous outcomes — simple and multiple linear regression.

Classification

Draw decision boundaries with logistic regression, multi-class models and decision trees.

Ensemble Learning

Combine many decision trees into a random forest, and watch the boundary smooth out.

Unsupervised Learning

Discover structure with no labels at all — K-Means clustering and association rule mining.

Neural Networks

Watch activations propagate forward, then train a network with backpropagation on XOR.

Applied ML

Build a collaborative-filtering recommendation engine from a live, editable ratings matrix.

HOW IT WORKS

Read it, run it, then try it yourself.

Every experiment follows the same three-step flow, so students always know what to expect.

STEP 01

Read the theory & code

A plain-language explanation of the concept, followed by runnable Python reference code and the output to expect.

STEP 02

Run the interactive demo

Add data points, tune parameters, and watch the algorithm respond live — right in the browser, no setup.

STEP 03

Check your understanding

Key-points summaries reinforce the intuition after every experiment, ready for lab writeups or viva questions.

WHY A VIRTUAL LAB

Built for a classroom, not a browser tab you forget about.

Traditional ML labs live in scattered notebooks and slide decks. This lab keeps the reference code, the theory, and a working demo of every algorithm together on one page — so students can revisit any experiment at exam time without hunting for the original files.

  • Works entirely offline once loaded — no server, no installs
  • Every algorithm runs client-side in plain JavaScript
  • Deployable for free on GitHub Pages in minutes
