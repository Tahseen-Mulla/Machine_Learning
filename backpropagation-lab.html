What is Backpropagation?

Backpropagation is the algorithm used to train a neural network's weights. After a forward pass produces a prediction, the error is propagated backward through the network using the chain rule, computing how much each weight contributed to the error:

1. Forward pass → compute prediction and loss (mean squared error here).
2. Backward pass → compute ∂Loss/∂w for every weight, layer by layer, from output back to input.
3. Gradient descent update → w ← w − η·(∂Loss/∂w)

The learning rate η controls the step size: too high and training overshoots or diverges; too low and it converges very slowly. XOR is the textbook example motivating hidden layers — a plain perceptron with no hidden layer can never learn it, no matter how it's trained, because XOR isn't linearly separable.
