What is a Random Forest?

A random forest is an ensemble of many decision trees. Two sources of randomness make the trees different from one another:

1. Bagging (Bootstrap Aggregating): each tree trains on a random sample of the data, drawn with replacement.

2. Feature/threshold randomness: each split considers slightly randomised candidate thresholds, so trees don't all make identical decisions.

For classification, the forest's final prediction is a majority vote across all trees. Averaging over many diverse, individually noisy trees reduces variance and typically gives a smoother, more accurate boundary than any single tree — try comparing this page's boundary shape to the single Decision Tree lab with the same points.
