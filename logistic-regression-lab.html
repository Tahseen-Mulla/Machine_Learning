What is Logistic Regression?

Logistic regression is used for binary classification. Instead of predicting a continuous value, it estimates the probability that an input belongs to class 1, using the sigmoid function to squeeze any real number into the range (0, 1):

Model:
P(y=1 | x) = 1 / (1 + e-(b₀ + b₁x))

A threshold (commonly 0.5) converts this probability into a predicted class.

The coefficients are learned by gradient descent, iteratively adjusting b₀ and b₁ to minimise log-loss (cross-entropy) between predicted probabilities and the true 0/1 labels — trained live in your browser each time you add a point.
