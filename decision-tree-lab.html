What is a Decision Tree?

A decision tree classifies data by asking a sequence of yes/no questions about feature values, like "is X ≤ 150?". At each internal node, the algorithm picks the split (feature + threshold) that most reduces class impurity in the resulting two groups, measured by the Gini index:

Gini = 1 − ∑ pi2, summed over each class's proportion pi in a node.
A Gini of 0 means the node is pure (only one class present).

Splitting continues recursively until a node is pure or the maximum depth is reached. Shallow trees generalise better; very deep trees can memorise the training points (overfitting) — try increasing the depth slider on noisy data to see this happen.
