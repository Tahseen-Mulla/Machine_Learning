What is a Neural Network?

A feed-forward neural network is a stack of layers of simple units (neurons). Each neuron computes a weighted sum of its inputs, adds a bias, then passes the result through a non-linear activation function:

aj = f( ∑i wij·xi + bj )

Hidden layers here use ReLU (f(z) = max(0,z)); the output layer uses softmax, turning raw scores into a probability distribution over classes.

Stacking layers lets the network combine simple linear pieces into complex, non-linear decision boundaries — something a single-layer model cannot do. This demo uses fixed (randomly initialised) weights purely to show how signals propagate; the Backpropagation lab shows how those weights are actually learned from data.
